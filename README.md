# 言语理解墨墨制卡方法

这是一套可复用的方法和执行流程，用于把公务员考试言语理解材料转化为真正有助于做题的墨墨卡片。

正式交付包括：

- `skills/verbal-maimemo-cards/`：可直接安装和调用的 Codex Skill；
- `maimemo_learning_rebuild/`：来源、词义、辨析、应用、冻结、授权、写入和回读校验；
- `tests/`：完全虚构的小样本和失败场景；
- `docs/制卡方法与流程.md`：普通用户使用说明。

仓库不包含任何真实卡片库、课程全文、墨墨编号、卡组章节编号、令牌、旧授权或线上快照。具体项目数据只能作为本机输入，不属于这套方法本身。

完成标准不是字段填满，而是每张卡能帮助学习者准确理解词义、抓住区别，并在新题中作出选择。
