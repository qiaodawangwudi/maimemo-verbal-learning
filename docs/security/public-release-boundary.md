# 公开发布边界

本仓库公开制卡规则、质量校验、合成测试数据，以及用户已经接受公开的学习内容。

下列内容不进入公开版本：

- 墨墨令牌或其他凭据；
- 历史 `write_approval.json`；
- 旧行动计划和旧线上只读快照；
- 真实卡片、根卡、卡组和章节编号的历史对照表；
- 含本机绝对路径的内部实施报告。

这些旧工件在清理前已经逐字节备份至本机 `.local-private/legacy-artifacts/`，该目录被 Git 忽略。公开的 `group_registry.json` 保留词义和辨析内容，但历史卡片编号已替换为稳定占位编号；实际发布必须重新读取目标章节并生成新的冻结清单。

869 张历史卡片形成于受保护发布流程建立前。它们可作为内容审核对象，但旧快照、旧计划和旧授权均不构成再次写入许可。新的写入只能使用 schema-v2 冻结发布物和 GitHub 最终授权。
