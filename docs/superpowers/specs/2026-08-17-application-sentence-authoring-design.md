# 应用句创作与改编设计

## 目标

应用卡必须帮助学习者在新题中准确选词。老师转写、原题和词典只用于核定义项、辨析轴与语境逻辑；未经改写的课堂口语不得成为正式题干。

## 题目形成方式

正式应用题只允许两种形成方式：

1. `authored`：依据已核定词义、特别之处、识别线索、判断维度和易错边界自主创作。
2. `adapted`：从原题或原材料提取有效逻辑，删除冗余信息、课堂互动和答案提示，重写为自然书面语。

每题内部保存 `construction`：形成方式、语义依据、来源依据和改写说明。该信息用于审计，不冒充老师原话，也不增加卡片正面的记忆负担。

## 内容结构

正面只显示完整语境与同层级候选词。背面依次显示答案、题干线索、匹配过程、逐项排除和迁移规则。题干不得直接复述定义，不得出现答案，不得依赖课堂上下文才能读懂。

## 质量门禁

以下情况直接失败：

- `construction.mode` 不是 `authored` 或 `adapted`；
- 缺少语义依据，或改编题缺少来源依据与改写说明；
- 包含“咱们、同学们、对不对、来看一下、可以吧、这个词”等课堂口语；
- 题干与证据原句完全相同；
- 答案不在候选项中、候选项重复或干扰项无逐项排除；
- 语境不足以唯一确定答案；
- 只是把词义解释句挖空。

## 数据流

原始转写与原题先进入素材队列；素材队列始终为 `pending`。人工理解语义后，选择自主创作或深度改编，形成结构化应用记录。应用质量门禁通过后，渲染器才生成卡片；审查哈希随后绑定动作计划和最终授权。
