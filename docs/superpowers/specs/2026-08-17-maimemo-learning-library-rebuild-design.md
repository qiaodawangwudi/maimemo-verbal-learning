# 墨墨言语词汇学习库全库重建设计

日期：2026-08-17  
状态：设计已完成，等待用户复核  
目标章节：默认积累

## 1. 项目目标

本项目不是单纯整理词义、修复格式或维护卡片数量，而是把现有言语词汇材料转化为能够支持公务员考试“言语理解与表达—逻辑填空”学习的长期词汇系统。

最高验收标准是学习效果：学习者能够清楚理解词义，抓住词汇的特别之处，从有效维度辨析近义词，并在新题语境中准确判断词语是否适用。来源审计、全库查重、语义档案、程序门槛和 API 同步都只为这一目标服务。

## 2. 项目范围

审查范围是“默认积累”章节的全部 730 张卡，而不是只处理三讲 400 词批次。

- 605 张基础词义卡全部纳入审查。
- 125 张近义辨析卡全部纳入审查。
- 三讲 360 词中，当前已有 344 张基础卡，另有 16 词尚无基础卡。
- 360 词之外的 261 张历史基础卡同样纳入审查。
- 历史 215 张正式版、《20260107 选词刷题4》《20260108 选词刷题5》及其他早期内容不享有免检资格。
- 一张辨析卡可能连接多个历史批次，必须在全库近义关系中判断，不能按批次割裂处理。

## 3. 总体原则

### 3.1 学习效果优先

卡片必须先回答“是否帮助理解、辨析和做题”，再考虑字段是否齐全。技术结构正确但不能形成做题判断的卡片仍然不合格。

### 3.2 后台完整，前台清晰

来源、证据、版本、动作理由和卡片 ID 保存在后台档案；墨墨卡片面向学习，只呈现对理解、记忆和做题有价值的内容。后台复杂度不得转嫁给学习者。

### 3.3 证据不等于照抄

老师转写用于确认课程实际讲授内容，但明显的口语残句、ASR 错误和未完成表达不能直接作为最终词义。最终表述应在忠实于证据的前提下整理成准确、完整、可理解的语言。

### 3.4 维度按需出现

主体、对象、褒贬、程度、范围、过程、结果、状态、主动被动、形成方式和搭配等维度，只在能够帮助区分或做题时出现。禁止为填满模板而机械罗列。

### 3.5 未通过全量审查不得写入

任何 API 写入必须晚于：全库来源台账、逐词判断档案、近义关系图、最终卡片预览、动作计划和机器审查。用户没有明确授权前，只允许读取。

## 4. 证据体系

### 4.1 老师课程转写

老师原话是课程口径的核心证据，用于恢复老师明确讲到的词义、褒贬、对象、搭配、例子、判断维度和近义差别。每项重要判断应能回到具体文件和段落。

### 4.2 用户直接补充

用户明确要求补充、但课程没有解释的词，可以使用可靠通用解释，来源标为用户补充或通用核定，不得标称老师讲过。

### 4.3 权威通用解释

权威词典或可靠资料可用于核正规范含义、纠正残句和补足课程没有讲清的通用边界。课程口径与通用补充在后台档案中分开记录。

### 4.4 现有卡片和历史模型结果

现有卡片、旧 registry、历史 manifest、人工中间档案和 DeepSeek 结果只用于查重、追溯和发现候选关系，不能反向证明词义正确。

### 4.5 证据不足

找不到原始依据、不同来源冲突或无法稳定裁定时，记录为 `pending` 或 `conflict`。不得为了让整批全部通过而自行补造结论。

## 5. 统一基础卡设计

基础卡采用“上层简明、下层深入”的分层结构。

### 5.1 卡片正面

正面以主动回忆为目标，默认提出：

> “词语”是什么意思？特别之处是什么？与最易混词怎样区分？

正面不直接泄露答案，不堆放来源或管理信息。

### 5.2 背面第一层：快速理解和提取

第一层必须在短时间内帮助学习者提取核心判断：

1. 一句话准确词义；
2. 特别之处，即该词独有或最值得记忆的语义落点；
3. 与最易混词的一句话差别；
4. 做题时最关键的识别点。

“特别之处”必须提供独立信息。若它只是重复词义，应改写或合并，不保留空栏目。

### 5.3 背面第二层：深入辨析

第二层按需提供：

- 主体与对象；
- 褒贬和语义方向；
- 程度与范围；
- 过程、结果与状态；
- 主动、被动和形成方式；
- 常见搭配；
- 易错边界；
- 能体现差别的典型语境。

没有独立学习价值的维度不显示。

### 5.4 近义关系

基础卡直接写出当前词与每个相关词的最小差别，并引用对应完整辨析卡的真实 `mkjr_` 根卡 ID。禁止使用“前者、后者、两者、二者、它俩、他俩”等模糊指代。

## 6. 统一辨析卡设计

辨析卡解决一个明确的学习问题：“这些容易混淆的词，做题时怎样选？”

### 6.1 组建原则

- 成员之间必须存在真实、稳定、对做题有价值的比较关系。
- 同一自然语义组尽量形成一张完整辨析卡。
- 不机械拆成大量重复的两两卡。
- 不因同属课程大章节就组成超宽大组。
- 一个词可以进入多个辨析角度，但每个组必须有独立学习价值。

### 6.2 内容结构

辨析卡包括：

1. 组内共同语义领域；
2. 每个词的一句话准确词义；
3. 每个词的特别之处；
4. 真正决定选择的比较维度；
5. 组内最小差别；
6. 必要的题干识别信号、易错条件或短语境。

最小差别不得复制词义，必须形成直接对照。

## 7. 做题迁移设计

卡片内容应支持以下判断链：

> 读取语境 → 找到逻辑对应点 → 选择有效判断维度 → 比较选项最小差别 → 排除不匹配词 → 确定最准确表达

只在能够训练上述链条时增加语境练习。应用内容不机械覆盖每个词，也不使用只能重复原题答案的低价值练习。

## 8. 全库恢复流程

### 8.1 冻结实时基线

保存全部 730 张卡的标题、内容、卡片 ID、根卡 ID、语法版本和章节归属，并记录快照哈希。后续所有差异均以冻结快照为起点。

### 8.2 建立全库来源台账

为每张卡记录来源批次、原始材料、规范词面、义项、现有内容可信度和证据状态。360 词之外的历史卡必须追溯《20260107》《20260108》及其他可用原始材料。

### 8.3 重建逐词判断档案

逐词恢复规范词面、义项、准确词义、语义核心、特别之处、有效判断维度、近义边、易错边界、来源证据和状态。现有 360 词 registry 仅保留词面与证据索引价值，其语义字段重新判断。

### 8.4 重建全库近义关系图

在全部词范围内判断自然语义组，识别相同组、包含组、部分重叠组、过宽组和无效组。近义组成员变化时，同步重算辨析卡和所有相关基础卡。

### 8.5 生成离线学习版卡库

在本地生成全部最终卡片内容，不调用写 API。每张现有卡被标记为：

- `unchanged`：内容与关系已符合学习标准；
- `update`：使用现有 card_id 原位改进；
- `manual-review`：证据不足或冲突；
- `create`：全库确认没有可复用卡后才允许；
- `repurpose`：无法删除的冗余卡原位改造成确实缺失的合格卡。

### 8.6 全量机器审查

写入前至少拦截：

- 重复词面、义项、标题或近义组；
- 相同、包含和部分重叠组未解释；
- 基础卡引用缺失或引用非 `mkjr_`；
- 模糊指代；
- 词义、特别之处和判断维度重复；
- 最小差别复制词义；
- 模板废话；
- 课程证据与通用补充混淆；
- 有新证据却标记 `unchanged`；
- 动作数量与预计写后总数不一致；
- 审查通过后的 manifest 哈希变化；
- 未审查的 `create`。

机器审查只能发现确定性结构与文本风险，不能替代近义关系和学习价值的人工语义判断。

### 8.7 经授权同步并全量回读

获得用户明确写入授权后，先写辨析卡并回读真实根卡 ID，再写基础卡。每次异常立即停止。写后按冻结计划核验总数、标题、内容、语法版本、引用、组覆盖和计划外新增量。

## 9. 学习效果验收

### 9.1 理解验收

学习者看完卡片后，能够不用照抄卡面，用自己的话说明词义及适用对象。

### 9.2 辨析验收

学习者能够说明当前词与近义词最关键的差别，而不是分别重复两个词的定义。

### 9.3 维度验收

学习者能够指出判断该词最有用的维度，并理解该维度为什么能区分选项。

### 9.4 迁移验收

面对未见过的短语境，学习者能够根据主体、对象、方向、程度、过程或结果等信息判断词语是否适用，并解释排除干扰词的原因。

### 9.5 记忆验收

卡片第一层足够简洁，可以在间隔复习时快速提取；第二层提供需要时的深入解释，但不干扰第一层记忆。

## 10. 当前安全边界

- 不运行旧同步脚本 `sync_four_poems_maimemo.py`。
- 不把现有卡片或旧 registry 当作正确答案。
- 不在逐词语义重建前补建缺失的 16 张基础卡。
- 不因成员数量自动拆组，也不因标题重叠自动合并。
- 不猜测未验证的删除接口。
- 用户未明确授权前，不调用任何墨墨写 API。

## 11. 交付物

完整恢复过程应形成：

1. 730 张卡的只读基线快照；
2. 全库来源与证据台账；
3. 全部词义的判断主档案；
4. 全库近义关系图和分组理由；
5. 全部最终卡片的离线学习版预览；
6. 逐卡动作计划与预计写后总数；
7. 机器审查报告和冻结 manifest 哈希；
8. 经授权写入后的全量回读报告；
9. 面向学习者的词汇学习总入口。

## 12. 成功定义

项目只有同时满足以下条件才算完成：

- 全部现有卡都经过来源、语义、学习价值和关系审查；
- 每个正式词义都有可说明的证据或明确的通用补充来源；
- 基础卡清楚呈现词义、特别之处、有效维度和近义差别；
- 辨析卡能够指导真实语境选词；
- 全库没有未解释的重复、重叠、缺失引用或计划外新增；
- 学习内容前台清晰，后台档案完整；
- 写入结果与冻结计划一致；
- 用户能够把卡片内容迁移到新的言语理解题中。
