# 学习质量量规

质量审查判断内容是否能帮助学习者理解、辨析和迁移。字段存在只通过结构检查；下列语义门槛必须逐项人工或可解释地判定。

## 语义档案

| 项目 | 通过标准 | 失败示例 |
|---|---|---|
| 词义 | 准确回答“是什么”，覆盖当前证据支持的语义边界 | 只换一种说法重复词面 |
| 特别之处 | 回答“为什么不是相近词”，给出可区分落点 | 与词义同义复述 |
| 做题识别点 | 给出材料或选项中可观察的触发线索 | “结合语境判断” |
| 易错边界 | 指出必要条件缺失、方向相反或对象不符时为何不能用 | “注意不要误用” |
| 证据 | 每个重要判断绑定来源、位置和短引文或可核动作 | 只写“老师讲过” |

新证据进入后，即使标题与结论文字暂时相同，也要判断它是支持、补充、限制还是推翻现有义项，并记录该决定。

## 辨析审查

先固定完整成员和义项，再审每一条边：

1. 分别陈述每个词的词义与特别之处。
2. 用最小差别说明在同一语境中为什么选一个而不选另一个。
3. 只保留有证据且能改变选择的维度，如主体/对象、程度范围、过程/结果、褒贬方向、主动被动、搭配和语境逻辑。
4. 检查每个成员是否与所有相关成员保持一致；不得只补一张卡。
5. 禁止用“前者、后者、两者、二者、它俩、他俩”代替词名。

任一成员、义项或最小差别变化，都使旧组审查失效。成员部分重叠不能证明同组，也不能单独证明可复用 `root_id`。

## 卡片层次

基础卡第一层固定为：

`词义 -> 特别之处 -> 做题识别点 -> 一眼辨析`

第二层仅在能增加训练价值时加入多维判断、易错边界、典型语境和完整辨析卡引用。空栏目省略，不用套话占位。

辨析卡逐词写词义和特别之处，再写真正的最小差别与判断维度。应用卡只有在独立训练价值明确且通过唯一性审查时创建。

## 应用审查

`uniqueness_rationale` 是解释载体，不是通过开关。按以下事实判定：

- 有且仅有一个选项由题干条件与已审语义共同支持。
- 对每个非最佳选项给出具体排除条件，不能只说“不如最佳”。
- 如果两个选项都符合、题干条件不足或排除理由依赖未证实常识，标记 `blocked`。
- 不得为追求唯一答案而改写已冻结语义；应退回题目或语义审查。

## 发布前质量结论

只有以下条件同时成立才能冻结：

- 所有正式义项为 `ready`，无证据冲突。
- 词义、特别之处和易错边界互不重复。
- 所有受影响比较组已按完整成员重建。
- 所有应用题通过事实唯一性审查。
- 卡片对学习者可扫描、可回忆、可迁移，不依赖隐藏上下文。
