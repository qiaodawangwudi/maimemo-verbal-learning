# 学习质量量规

质量审查判断内容是否能帮助学习者理解、辨析和迁移。字段存在只通过结构检查；下列语义门槛必须逐项人工或可解释地判定。

## 语义档案

| 项目 | 通过标准 | 失败示例 |
|---|---|---|
| 词义 | 准确回答“是什么”，覆盖当前证据支持的语义边界 | 只换一种说法重复词面 |
| 核心辨析 | 两至四个关键词槽，以 ` + ` 连接，直接给出能决定选词的条件、对象、动作或结果 | “这个词重某种具体语义落点”或完整长句 |
| 题干关键词 | 给出材料或选项中可直接观察的触发线索，并且不重复核心辨析 | 把核心辨析换一种说法再写一遍 |
| 易错边界 | 指出必要条件缺失、方向相反或对象不符时为何不能用 | “注意不要误用” |
| 证据 | 每个重要判断绑定来源、位置和短引文或可核动作 | 只写“老师讲过” |

新证据进入后，即使标题与结论文字暂时相同，也要判断它是支持、补充、限制还是推翻现有义项，并记录该决定。

`approved` 是逐词复核结论，不是生成器默认值。自动抽取、字段补齐、本地规则通过或旧工件写着 `ready`，均不能代替词义、核心辨析、边界、做题落点和证据的实际复核；未完成时必须标为 `pending`。预览可以只呈现已审子集，但必须显式报告待审数量和清单。

## 辨析审查

先固定完整成员和义项，再审每一条边：

1. 分别且只陈述一次每个词的关键词式核心辨析与完整词义。
2. 用“怎么选”说明出现何种决定性线索时选择哪个具体词；只有确有新增信息时才加入词对差异。
3. 只保留有证据且能改变选择的维度，如主体/对象、程度范围、过程/结果、褒贬方向、主动被动、搭配和语境逻辑。
4. 检查每个成员是否与所有相关成员保持一致；不得只补一张卡。
5. 禁止用“前者、后者、两者、二者、它俩、他俩”代替词名。

任一成员、义项或最小差别变化，都使旧组审查失效。成员部分重叠不能证明同组，也不能单独证明可复用 `root_id`。

同一课程段落、旧 `group_key`、词面相邻或单向边界提名只产生候选关系。正式近义组还须满足：成员义项均已审、边界双向指认、每个选择条件能落到具体词、观察可定位。若某条边界混入第三个词或无法形成封闭组，必须拒绝该候选，不得用自动连通分量扩组。

## 卡片层次

基础卡主体固定为：

`核心辨析 -> 词义 -> 一眼辨析 -> 多维判断`

再按信息增量保留易错边界、典型语境和完整辨析卡引用。题干线索只能在主体之后以 `附加｜题干可圈出` 出现，不得替代主体栏目。一眼辨析只输出具体词对的最短差别。多维判断必须同时具有至少两个彼此独立、核心辨析未覆盖且能改变选词的新维度；少于两个时整栏不显示，但不得从制卡方法中删除这项审查。若已审词对材料明确支持两个以上新增轴而成品多维判断整批为零，则生成结果失败。

辨析卡依次写 `核心辨析 -> 词义 -> 一眼辨析 -> 多维判断 -> 怎么选`。每个词只解释一次；同一句总括不得复制到多个词对，判断维度不得换句话重复逐词核心。应用卡只有在独立训练价值明确且通过唯一性审查时创建。

### 信息增量硬检查

- 同一卡片内，将标点和栏目名去除后，相同判断出现两次即失败。
- 核心辨析少于两个有效关键词槽、没有 ` + ` 或仍是解释性长句即失败。
- `附加｜题干可圈出` 与核心辨析同义复述即失败；附加线索必须能在题干中直接圈出，并且删去整项后卡片主体仍须完整可学。
- 组内每个词只保留一条核心辨析；不得把整组总括句逐边复制。
- 一眼辨析必须绑定两个具体词，只保留最短对立落点；整组长句或两个相同词对句即失败。
- 多维判断必须至少提供两个彼此独立、核心辨析没有覆盖且会改变选词的维度；辨析卡的每个维度还必须至少比较两个具体成员。少于两个轴时整栏省略。
- 维度先审后用：每个近义组必须在独立 `dimension_review` 中给出 `approved_dimensions` 或 `insufficient_dimensions`。生成器只能消费审查结果，不能自己补轴；所有组均判不足、缺少组处置、固定轴组合与固定判断骨架占据多数，均失败。
- 审定维度逐成员绑定原始字段哈希和原文摘录，并提供“改变条件会从哪个词切换到哪个词”的检验。合法轴名可以跨组重复；只有轴、判断骨架和证据一起机械重复时才属于高度同质化。
- `选择落点`、`落点`、`核心辨析`、`词义`、`题干关键词`、`一眼辨析`、`怎么选` 是栏目或结论，不是维度名；用这些名称填轴一律失败。
- `易错边界` 只有在给出缺失条件、反向条件或对象不符时保留，否则删除。

## 应用审查

`uniqueness_rationale` 是解释载体，不是通过开关。按以下事实判定：

- 有且仅有一个选项由题干条件与已审语义共同支持。
- 对每个非最佳选项给出具体排除条件，不能只说“不如最佳”。
- 如果两个选项都符合、题干条件不足或排除理由依赖未证实常识，标记 `blocked`。
- 不得为追求唯一答案而改写已冻结语义；应退回题目或语义审查。
- 场景必须是人物、机构或事物实际发生的事件；出现“题干先写到”“又明确出现”“题干没有说”“材料呈现出”等出题说明，或把核心辨析改写成定义问句，一律失败。
- 选项数量为 2—4 个，以真实混淆关系为准。双词组只给两个相关选项是合格的；为了凑满四项加入不相干词，反而失败。
- 解析只解释答案成立的决定性落点和实际误选项为何不成立；不得在“选择落点、干扰项排除、总结”中连续复述同一段定义。

## 发布前质量结论

只有以下条件同时成立才能冻结：

- 所有正式义项为 `ready`，无证据冲突。
- 核心辨析、词义、题干关键词和易错边界互不重复。
- 所有受影响比较组已按完整成员重建。
- 所有应用题通过事实唯一性审查。
- 卡片对学习者可扫描、可回忆、可迁移，不依赖隐藏上下文。
